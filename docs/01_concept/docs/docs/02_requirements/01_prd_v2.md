## 🔑 2. 핵심 기능 요구사항 개정 상세 명세

### 🛋️ [REQ-03 개정] 마음소파 통제 원 제스처 가이드라인 고도화
- **기능 분류**: Must-Have | **화면 ID**: `S-01_마음소파`
- **개정 목적**: 처음 사용하는 유저가 드래그 앤 드롭 방식을 즉각 인지하도록 조작의 직관성을 보장함 (학습 용이성 극대화).
- **상세 규격**:
  1. 인지왜곡 진단 후 드래그할 생각이 적힌 카드가 노출될 때, 손가락 드래그 모션 아이콘이 화면 중앙 원 방향으로 1회 스와이프되는 제스처 펄스 애니메이션을 제공한다.
  2. 모바일 웹 환경의 특성을 고려하여 드래그 조작 외에도 카드를 더블클릭/더블탭 했을 때 '통제 가능 원'으로 즉시 자동 배치되는 병렬 선택 조작을 지원한다.

---

### 💾 [REQ-04 개정] 행동 목표 달력 연동 양방향 취소 복귀 및 세션 보존
- **기능 분류**: Must-Have | **화면 ID**: `S-01_마음소파`
- **개정 목적**: 연동 과정 중 이탈/취소 분기에서 기입했던 감정 텍스트가 모두 초기화되는 Blocker 수준의 오류 복구 실패 장벽을 해소함.
- **상세 규격**:
  1. 달력 연동 의사를 묻는 Confirm Modal(팝업) 우측 상단에 닫기(X) 버튼을 의무 배치한다.
  2. 사용자가 실수나 변심으로 '나중에 할게요' 혹은 외부 Dimmed 영역을 클릭했을 때, 이미 타이핑 완료한 일기 텍스트 원문과 NLP 감정 진단 상태를 로컬 임시 세션(Local Session)에 100% 온전히 보존한 채 이전 완료 상태의 화면으로 원상 복구시킨다.

---

### 💬 [REQ-05 개정] 온답 지능형 소통 2-Step 칩 전송 피드백 구조
- **기능 분류**: Must-Have | **화면 ID**: `S-02_온답`
- **개정 목적**: AI 추천 대화 카드를 터치하자마자 상대 가족에게 즉각 메시지가 전송되어 발생하는 불안감을 차단하고, 최종 검토를 마친 후 발송할 수 있는 심리적 통제권을 보장함.
- **상세 규격**:
  1. SET-UP 추천 대화 칩(Chip) 터치 시 상대에게 곧바로 발송되지 않고, 인앱 메신저 텍스트 입력 필드 내부로 타이핑되듯 문장이 스무스하게 자동 주입(Insert)된다.
  2. 문장이 주입되는 즉시 비활성화되어 있던 [전송] 비행기 버튼이 활성 상태로 토글되며, 사용자가 최종적으로 원하는 어조로 글을 가다듬은 뒤 명시적으로 발송할 수 있도록 2단계 전송 구조를 확립한다.
