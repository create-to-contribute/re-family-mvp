## 2. 핵심 요구사항 상세 규격

### 2.1 [REQ-03 개정 v2.7] 마음소파(가칭) 3D 공간 및 감성 인터랙션
1. **자연 산책로 진입**: Three.js r128 기반의 3D 라벤더 산책로를 제공하여, 사용자가 직접 자연의 소리를 들으며 오두막으로 걸어 들어가는 조작의 재미와 시각적 안정감을 부여한다.
2. **4대 감성 인테리어 테마**: 상단 칩 스위칭을 통해 4가지 가상 공간 테마를 실시간 렌더링 전환하며, 실내 조명 밝기 및 소품이 연동된다 (노을빛 오두막, 햇살 화원 테라스, 달빛 심야 다실, 단정한 안심 상담실).
3. **3초 온기 호흡 찻잔**: 테이블 위의 찻잔 오브젝트를 터치 시, 파티클 스팀 효과와 함께 *"후~ 3초간 깊게 숨을 내쉬어 보세요"* 가이드 모달이 팝업되어 정서 이완과 호흡 조절을 돕는다.
4. **맞은편 AI 캐릭터 독대**: 사용자가 빈 소파에 착석 시 맞은편 소파에 따뜻한 AI 캐릭터가 앉아 대화를 건네며, 사용자는 음성 또는 텍스트 채팅을 통해 감정과 응어리를 안전하게 정화한다.

### 2.2 [REQ-11.5 신설 v2.7] 비동기 백업 서명 보안 및 유효기간 가드레일
1. **발신 신뢰성**: 카카오톡 공식 비즈니스 채널(노란색 안심 방패 배지) 알림톡을 통해서만 1회용 백업 서명 단축 링크를 발송하며, 공인 보안 도메인(`sign.re-family.kr`)만을 화이트리스트 적용한다.
2. **단회성 일회용 토큰**: HMAC-SHA256 기반 128-bit 암호화 세션 토큰을 적용한다. 서명이 1회 완료되는 즉시 토큰을 무효화하여 재접속 및 리플레이 공격을 원천 차단한다.
3. **2차 본인확인 게이트**: 링크 클릭 시 즉시 서식 원문을 노출하지 않고, 수혜 대상자(부모님)의 생년월일 6자리를 정확히 입력해야만 서식 상세 뷰어로 진입을 허용한다.
4. **유효기간 및 주말 예외 규격**: 기본 유효시간은 발송 후 24시간으로 제한한다. **단, 금요일 및 공휴일 전일 진행된 복지 상담 건은 토·일 휴무일을 산입하지 않고 차주 월요일(익영업일) 낮 12:00(정오)까지 마감을 자동 유예**하여 가족 간 숙의 시간을 합법적으로 보장한다.
5. **무저장 영구 파기 (Zero-Persistence)**: 유효기간 만료 시 임시 서식 캐시 데이터는 즉시 영구 삭제(Shredding)하며, 공공 행정망 API 전송 완료 즉시 중계 서버의 서식 데이터는 흔적 없이 소멸한다.
