# 🎨 [re-family] 04. 화면설계서 및 UI 흐름 (Screen Specs)

* **기준 버전**: v2.7 (최신 단일 진실 공급원)
* **작성자**: 변지선
* **업데이트 일자**: 2026년 11월 20일

---

## 1. 개별 화면설계 명세

### 1.1 S-00 온보딩 (Onboarding)
* 30초 돌봄 자격 자가 진단 필터 제공. 불필요한 정보 소음을 제거하고 실제 수혜 가능한 체감 혜택 안내에 집중하여 공공 서비스 탈락 시의 2차 정서 좌절 예방.

### 1.2 S-01 마음소파(가칭) 3D 뷰포트
* **3D 웰컴 인트로**: "문밖의 소음은 잠시 두고..." 안내 배너 및 절차적 사운드스케이프 시작 버튼 노출.
* **가상 산책로 및 오두막**: 3D 라벤더 산책로 조작 진입 및 4대 인테리어 테마/사운드 전환 칩 바 제공.
* **3초 온기 호흡 찻잔**: 테이블 위 찻잔 터치 시 스팀 파티클 애니메이션과 함께 이완 호흡 모달 표출.
* **소파 대화 모드**: 소파 터치 시 하단에 글래스모피즘(Glassmorphism) 기반 음성/채팅 입력창 노출. 맞은편 소파의 AI 캐릭터와 대화 개시.

### 1.3 S-02 온답(가칭) 소통방
* SET-UP 대화법 기반 추천 칩 바 제공. 터치 시 입력창에 추천 문장이 1차 주입(Step 1)되며, 사용자가 검토 및 편집 후 발송(Step 2)하는 안전 전송 가드레일 가동.

### 1.4 S-02 연동 얼굴 통화(가칭)
* **비식별 비디오 화면**: WebRTC 비디오 캔버스와 온디바이스 얼굴/상체 랜드마크 3D 아바타 실시간 자동 배경 합성 오버레이.
* **가상 복지 상담실 모드**: 주민센터/복지관 연결 시 3자 동석 뷰(자녀-부모-복지사) 및 전자 서식 공동 검토 모달 활성화.
* **[UI-11 보강 v2.6] 간편인증 및 대리 신청 위임 플로우**:
  * *Step 1*: 복지사가 서식 사전 입력 후 [전자서명 요청] 전송.
  * *Step 2*: 부모님 화면에 "자녀에게 대리 신청 권한을 위임하겠습니까? [위임 동의]" 원터치 팝업 표출.
  * *Step 3*: 자녀 화면에 PASS/카카오페이 공인 간편인증 모달 즉시 호출 및 서명 완료 배너 출력.

### 1.5 [S-05 신설 v2.7] 복지사 전용 관리 대시보드 (Admin UI)
* **4단계 상태 칸반 보드**: `[서명 대기]`, `[★마감 임박 (주말 유예)]`, `[서명 완료]`, `[기간 만료]` 필터링 제공.
* **1-클릭 리마인드**: 마감 임박 가구 대상 공식 알림톡 1-클릭 즉시 재발송 및 유선 전화 확인 링크 연동.
* **행복e음 공공망 일괄 접수**: 월요일 정오 마감 후 서명 완료 상태인 건들을 선택하여 공공 복지 API 일괄 전송 자동화.
